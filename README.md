# Python Projects

In this repository, I have added some Python projects that I made while learning Python. I made these projects to practise coding and learn new things. These are simple projects but they helped me understand Python better.

## Projects

1. Calculator - Used to perform basic calculations like addition, subtraction, multiplication and division.

2. KBC Quiz Game - A simple quiz game where we have to answer questions from the given options.

3. QR Code Generator - This project creates a QR code from a URL or text and saves it as an image.

4. Drink Water Reminder - This program reminds us to drink water every hour by sending a notification.

5. News API - This project shows news articles according to the topic entered by the user.

6. PDF Merger - Used to combine multiple PDF files into one PDF file.

7. AI Chatbot - A simple chatbot that uses the OpenAI API to give answers to user questions.

## Requirements

- Python installed on the computer
- VS Code or any other code editor
- Required Python libraries
- API keys for the news and chatbot projects

## Installation

First, download this repository and open it in VS Code.

Install the required libraries using this command:

python -m pip install "qrcode[pil]" requests openai PyPDF2 plyer

## How to Run

Open the terminal in VS Code and run the Python file of the project you want to use.

For example:
python calculator/main.py
You can run the other projects in the same way by using their file paths.
